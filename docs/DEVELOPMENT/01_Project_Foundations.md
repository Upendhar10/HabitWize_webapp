# Project Foundations

This phase establishes the foundational structure of the project before implementing any project-specific functionality.

The goal is to set up the development environment, project workspaces, tooling, and core configurations required to build and maintain a modern full-stack application.

This phase includes:

- Setting up the frontend and backend workspaces.
- Configuring root-level workspace management.
- Establishing Git and development tooling.
- Setting up the initial frontend and backend foundations.

---

## 1. Frontend Project Foundations

### 1.1 `chore(frontend): initialize React app using Vite`

**What I did**

- Bootstrapped the React application using Vite.
- Chose TypeScript as the primary language for the frontend.
- Removed the default boilerplate code generated by Vite.

**Why**

- Chose Vite for its fast development server, modern build tooling, and streamlined React setup.
- Chose TypeScript to improve type safety, code maintainability, and developer experience as the application grows.
